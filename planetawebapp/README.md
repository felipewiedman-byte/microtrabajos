# PLANETA

**El mundo está pasando. Descúbrelo ahora.**

Red social para descubrir lo que está ocurriendo en cualquier parte del mundo: eventos, lugares, planes, noticias, deportes, ciencia y vida cotidiana.

## Secciones
- **Planeta**: mapa mundial interactivo (Leaflet + OpenStreetMap/CARTO).
- **Ahora**: feed con Cerca de mí, Mi país, Mundo y En directo.
- **Publicar**: foto o video, texto, categoría y ubicación.
- **Cerca**: planes y eventos a tu alrededor.
- **Comunidad**: conversaciones, perfil y guardados.

## Desarrollo
```bash
npm install
npm run dev
```

Se publica automáticamente en GitHub Pages con cada cambio en `main`.
